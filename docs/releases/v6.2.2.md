## Cài đặt

- **Đã cài bản 6.2.x:** không cần làm gì. App tự tải bản này khi mở, cài đè và mở lại. Cài đặt và đăng nhập được giữ nguyên.
- **Windows (cài mới):** tải **AutoBrowser-Setup-6.2.2.exe** ở phần *Assets* bên dưới rồi chạy (không cần quyền admin). Nếu Windows cảnh báo, bấm *More info → Run anyway*.
- **Docker:** `docker compose pull && docker compose up -d`, rồi mở http://localhost:8000.
- Hướng dẫn đầy đủ: [INSTALL.md](https://github.com/Thequancute215-sys/Auto-Browser/blob/main/INSTALL.md)

## Có gì mới trong 6.2.2

Bản này là bản vá **tăng cường bảo mật**, rà soát từ một đợt audit mã nguồn. Không đổi tính năng, không ảnh hưởng cách dùng; chỉ siết thêm phòng vệ cho tình huống trang web độc hại cố điều khiển AI. Chưa ghi nhận trường hợp bị khai thác trên thực tế — đây là phòng xa.

**An toàn hơn khi AI duyệt trang lạ**
- AI chỉ được điều hướng tới địa chỉ web `http`/`https`. Trước đây một trang độc hại có thể gài để AI mở `file://` (đọc file trên máy, kể cả file chứa API key) hoặc `data:`/`javascript:`. Việc bạn tự mở file trên giao diện vẫn bình thường.
- Bản desktop giữ nguyên "hộp cát" (sandbox) của Chromium khi duyệt web — lớp ngăn chính nếu gặp trang khai thác lỗi trình duyệt. (Trước đây sandbox bị tắt sẵn; nay chỉ tắt trong Docker, nơi bắt buộc.)

**Cập nhật an toàn hơn**
- Khi tự cập nhật, app **từ chối chạy bộ cài nếu thiếu mã kiểm tra (digest)**, thay vì cài mà không xác minh. File tải về vẫn luôn được đối chiếu SHA-256 như trước; nếu không khớp thì hủy.

**Giới hạn đã biết:** một số trang có hệ thống chống bot (ví dụ British Council) chặn bản Docker (trình duyệt chạy ngầm). App desktop vào bình thường.
